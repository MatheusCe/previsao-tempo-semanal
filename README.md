# ☀️ Monitor de Previsão do Tempo e Recomendações

Aplicação em Python que consome a API da OpenWeatherMap para fornecer o clima atual e a previsão dos próximos dias com recomendações personalizadas para a rotina diária (alertas de chuva por horário, agasalho, umidade do ar e hidratação).

##  Funcionalidades

- **Clima Atual:** Exibe temperatura, sensação térmica, umidade e condição do tempo.
- **Previsão Semanal:** Agrupa as leituras por dia e indica a probabilidade de chuva em intervalos específicos.
- **Resumo Inteligente:** Sugere automaticamente se é necessário levar guarda-chuva, vestir casaco ou beber mais água com base na variação de temperatura e umidade.

##  Tecnologias Utilizadas

- **Python 3.11+**
- **Requests:** Para consumo da API REST do OpenWeatherMap.
- **Python-dotenv:** Para gerenciamento seguro das credenciais via variáveis de ambiente.
